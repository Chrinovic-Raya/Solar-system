```python 
from picam2 import Picamera2
import time

picam2 = Picamera2()
config = picam2.create_preview_configuration(main={"size": (640, 480)})
picam2.configure(config)
picam2.start()

print("Camera initialized. Capturing in 2 seconds...")
time.sleep(2)

picam2.capture_file("opencv_test.jpg")
picam2.stop()
print("Saved opencv_test.jpg successfully!")
```
